## Description

D005 Data Hub 為 HORUS-PDM 系統的 FACT 資料中樞，負責：
- 原始資料收集與整合
- T005 商品庫寫入管理
- T002 物料庫寫入管理

## Governance Rules

1. **不得推斷或補齊**: 缺失資料必須標記為空，不得自動填補
2. **來源追蹤**: 所有寫入必須記錄資料來源
3. **Schema 權威**: D005 為 T005/T002 Schema 的唯一寫入者
4. **禁止直接操作**: 其他模組不得繞過 D005 直接寫入 FACT
