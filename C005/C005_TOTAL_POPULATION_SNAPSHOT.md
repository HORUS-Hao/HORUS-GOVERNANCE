# C005 Total Population Snapshot (Phase 1)

## 定義
C005 上架率母數為 runtime 計算集合，非單一實體表。

## 組成來源
- T005 Canonical 商品主檔
- ERP 商品資料（數量 / 成本 / 料號）
- D005 Listing_History（平台觀測結果）

## Phase 1 說明
- 未套用 listing-eligible 規則
- 未排除停用 / 不可售商品
- 僅作「現況觀測」用途

## 治理聲明
本母數僅適用於 Phase 1（Observation）。
Phase 2 起將以 eligibility 規則重算。
