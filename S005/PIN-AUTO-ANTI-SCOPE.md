# PIN 自動驗證不可延伸清單（Anti-Scope）

- 文件：PIN-AUTO-ANTI-SCOPE.md
- 版本：v1.0.0
- 建立日期：2026-01-08
- 狀態：**範圍限制文件**
- 範圍：**僅限 pin_tmp / pin_hash**

---

## 總裁定

> **本任務僅解決 PIN 正確性是否可被自動判斷，**
> **不解決放行、不解決權限、不解決責任歸屬。**

---

## 一、本任務不能順便做的事

### 1.1 禁止延伸清單

| # | 禁止事項 | 原因 |
|---|----------|------|
| 1 | ❌ 修改 OTP 驗證流程 | 超出 pin_tmp / pin_hash 範圍 |
| 2 | ❌ 修改 Session 管理邏輯 | 超出 pin_tmp / pin_hash 範圍 |
| 3 | ❌ 新增 PIN 複雜度規則 | 改變驗證標準 |
| 4 | ❌ 新增 PIN 有效期限 | 改變安全策略 |
| 5 | ❌ 自動重設 PIN | 涉及權限決策 |
| 6 | ❌ 自動解鎖帳號 | 涉及權限決策 |
| 7 | ❌ 自動通知 PIN 錯誤 | 超出驗證範圍 |
| 8 | ❌ 修改 Role 權限對應 | 觸碰 Authority |
| 9 | ❌ 修改 State Machine | 觸碰 Authority |
| 10 | ❌ 修改 Approval Flow | 觸碰 Authority |
| 11 | ❌ 新增 biometric 驗證 | 新增驗證方式 |
| 12 | ❌ 整合外部 Identity Provider | 架構變更 |
| 13 | ❌ 修改 Company_Profile | 超出範圍 |
| 14 | ❌ 修改 USERS_ACCESS | 超出範圍 |
| 15 | ❌ 修改 Admin_OTP 結構 | 超出範圍 |

### 1.2 「順便」的定義

以下說法視為違規：

| 違規說法 | 原因 |
|----------|------|
| 「可以順便優化 OTP 流程」 | 超出範圍 |
| 「順便加上 PIN 複雜度檢查」 | 改變標準 |
| 「既然看了 Session，順便改一下」 | 範圍蔓延 |
| 「這裡有個 bug，順便修」 | 必須另開任務 |
| 「效能不好，順便優化」 | 超出範圍 |

## 三、明確聲明：任何擴張需 Architect 新裁定

### 3.1 擴張定義

以下情況視為「擴張」：

| 類型 | 範例 |
|------|------|
| **範圍擴張** | 從 pin_hash 擴展到 OTP |
| **功能擴張** | 從驗證擴展到重設 |
| **自動化擴張** | 從驗證擴展到放行 |
| **欄位擴張** | 新增任何欄位 |
| **流程擴張** | 修改任何現有流程 |

### 3.2 擴張申請流程

```
發現需要擴張
    ↓
停止當前任務
    ↓
提交擴張申請（含理由）
    ↓
Architect 評估
    ↓
核准 → 開新任務
    ↓
拒絕 → 維持原範圍
```

### 3.3 未經核准的擴張後果

| 後果 | 說明 |
|------|------|
| 任務失敗 | 整個任務視為 FAIL |
| 必須回滾 | 所有超出範圍的內容必須撤銷 |
| 重新審查 | 需重新進行任務評估 |
