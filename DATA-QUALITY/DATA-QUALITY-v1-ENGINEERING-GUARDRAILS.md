## 一、文件目的

本文件定義 Data Quality v1 的工程實作護欄，明確規範**允許做的事**與**禁止做的事**。

**核心原則**：
> **v1 = Read-only Audit + Report-only**
> **不自動修正、不阻斷流程、不碰 Authority**

## 二、允許做的事

### 2.1 資料讀取

| 允許項目 | 說明 | 條件 |
|----------|------|------|
| ✅ 讀取 S005_QUOTES | 全表或指定範圍 | Read-only |
| ✅ 讀取 Company_Profile | 全表 | Read-only |
| ✅ 讀取 USERS_ACCESS | 全表 | Read-only |
| ✅ 讀取 Admin_Users | 非敏感欄位 | 排除 otp_code |
| ✅ 讀取 Admin_Sessions | 非敏感欄位 | 排除 token 內容 |
| ✅ 解析 JSON 欄位 | items_json, snapshot_json | JSON.parse |

### 2.2 品質檢查

| 允許項目 | 說明 | 範圍 |
|----------|------|------|
| ✅ 必填欄位檢查 | 檢查欄位是否存在/非空 | FACT-QUALITY-RULESET-v1 定義 |
| ✅ 型別檢查 | 檢查資料型別是否正確 | String/Number/Date/JSON |
| ✅ 格式檢查 | 檢查格式是否符合規則 | Email/RefId/Timestamp |
| ✅ 值域檢查 | 檢查值是否在允許範圍 | Enum/Range |
| ✅ 唯一性檢查 | 檢查主鍵是否重複 | ref_id/email/token |
| ✅ 參照完整性檢查 | 檢查外鍵是否存在 | Company/User |
| ✅ 一致性檢查 | 檢查狀態與欄位邏輯 | State-Field Mapping |

### 2.3 報告產出

| 允許項目 | 說明 | 格式 |
|----------|------|------|
| ✅ Summary 報告 | 總筆數/通過數/錯誤數 | Markdown |
| ✅ Top-N 錯誤清單 | 最常見問題排序 | Markdown/JSON |
| ✅ 明細報告 | 錯誤欄位/ref_id/值 | Markdown/JSON |
| ✅ 健康分數 | 品質評分計算 | Number |
| ✅ Console Log | 執行過程記錄 | Logger.log |

### 2.4 執行方式

| 允許項目 | 說明 | 觸發方式 |
|----------|------|----------|
| ✅ 手動執行 | 管理員主動觸發 | UI 按鈕 / 函數呼叫 |
| ✅ 排程執行 | 定時自動執行 | Time-based Trigger |
| ✅ 獨立 Script | 分離於主業務邏輯 | 獨立 .gs 檔案 |

## 三、明確禁止事項

### 3.1 嚴禁回寫

| 禁止項目 | 說明 | 原因 |
|----------|------|------|
| ❌ setValue() | 任何寫入單一儲存格 | FACT 不可變 |
| ❌ setValues() | 任何批次寫入 | FACT 不可變 |
| ❌ appendRow() | 任何新增資料列 | 不可新增 FACT |
| ❌ deleteRow() | 任何刪除資料列 | 不可刪除 FACT |
| ❌ insertRowAfter() | 任何插入資料列 | 結構不可變 |
| ❌ 修改 JSON 欄位 | 修改 items_json / snapshot | 內容不可變 |

### 3.2 嚴禁自動修正

| 禁止項目 | 說明 | 原因 |
|----------|------|------|
| ❌ 自動補值 | 檢測到缺失後自動填入 | 資料真實性 |
| ❌ 自動轉型 | 檢測到型別錯誤後自動轉換 | 資料原貌 |
| ❌ 自動格式化 | 檢測到格式錯誤後自動修正 | 來源追溯 |
| ❌ 自動去重 | 檢測到重複後自動刪除 | 資料完整性 |

### 3.3 嚴禁阻斷流程

| 禁止項目 | 說明 | 原因 |
|----------|------|------|
| ❌ throw Error | 品質問題不得拋出例外 | 不中斷業務 |
| ❌ return false | 品質問題不得阻擋寫入 | 業務優先 |
| ❌ 修改 S005 核心邏輯 | 不得在業務函數內加檢查 | 關注分離 |
| ❌ 修改 V005 核心邏輯 | 不得在業務函數內加檢查 | 關注分離 |

### 3.4 嚴禁 Derived 計算

| 禁止項目 | 說明 | 原因 |
|----------|------|------|
| ❌ 計算衍生欄位 | 基於 FACT 計算新值 | v1 範圍外 |
| ❌ 交叉推導 | A 欄位推導 B 欄位 | 邏輯污染 |
| ❌ 跨模組同步 | S005 → T005 同步 | 範圍外 |
| ❌ 預測填補 | 歷史資料預測缺失值 | 資料失真 |
