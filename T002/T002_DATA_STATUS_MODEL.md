# T002 資料狀態模型

**文件類型**: Governance Standard
**狀態**: Active
**適用範圍**: T002 原料清洗系統
**生效日期**: 2026-01-13
**上位文件**: ADR-T002-COLLABORATION-PHASE1.md

---

## 一、Purpose

本文件定義 T002 商品記錄的狀態模型，用於：

- 描述商品資料在 T002 內的生命週期
- 明確各狀態的邏輯意義
- 定義狀態轉換的治理規則

本文件**僅描述邏輯意義，不涉及任何觸發程式或自動化**。

---

## 二、狀態定義

### 2.1 主狀態清單

| 狀態代碼 | 狀態名稱 | 邏輯意義 |
|----------|----------|----------|
| `INCOMPLETE` | 資料不完整 | P0 或 P1 欄位有缺失 |
| `WAITING_SUPPLIER` | 等待供應商 | 缺失資料需由供應商補齊 |
| `WAITING_BRAND` | 等待品牌方 | 缺失資料需由品牌方補齊 |
| `WAITING_INTERNAL` | 等待內部處理 | 缺失資料需由內部人員補齊 |
| `PENDING_AI_CLEAN` | 待 AI 清洗 | 已收到原始資料，尚未清洗 |
| `AI_CLEANING` | AI 清洗中 | 清洗程序進行中 |
| `PENDING_HUMAN_CONFIRM` | 待人工確認 | AI 清洗完成，信心度不足，需人工確認 |
| `READY_FOR_T005` | 可轉入 T005 | 資料完整，可進行轉入 |
| `T005_TRANSFERRING` | 轉入中 | 正在轉入 T005 |
| `LOCKED_AFTER_T005` | 已轉入鎖定 | 已轉入 T005，T002 記錄唯讀 |

### 2.2 狀態分類

| 分類 | 狀態列表 | 說明 |
|------|----------|------|
| **初始狀態** | `PENDING_AI_CLEAN` | 資料進入 T002 的起點 |
| **處理中狀態** | `AI_CLEANING`, `PENDING_HUMAN_CONFIRM` | 清洗流程進行中 |
| **等待狀態** | `WAITING_SUPPLIER`, `WAITING_BRAND`, `WAITING_INTERNAL` | 等待外部補齊 |
| **阻斷狀態** | `INCOMPLETE` | 無法前進，需處理 |
| **就緒狀態** | `READY_FOR_T005` | 可進行轉入 |
| **終態** | `LOCKED_AFTER_T005` | 流程結束 |

## 三、狀態轉換規則

### 3.1 正向流程（Happy Path）

| 起始狀態 | 目標狀態 | 轉換條件 |
|----------|----------|----------|
| `PENDING_AI_CLEAN` | `AI_CLEANING` | 清洗程序啟動 |
| `AI_CLEANING` | `READY_FOR_T005` | 清洗完成，信心度 ≥ 閾值 |
| `AI_CLEANING` | `PENDING_HUMAN_CONFIRM` | 清洗完成，信心度 < 閾值 |
| `PENDING_HUMAN_CONFIRM` | `READY_FOR_T005` | 人工確認完成 |
| `READY_FOR_T005` | `T005_TRANSFERRING` | 轉入程序啟動 |
| `T005_TRANSFERRING` | `LOCKED_AFTER_T005` | 轉入完成 |

### 3.2 異常處理流程

| 起始狀態 | 目標狀態 | 轉換條件 |
|----------|----------|----------|
| `AI_CLEANING` | `INCOMPLETE` | 清洗發現 P0/P1 欄位缺失 |
| `PENDING_HUMAN_CONFIRM` | `INCOMPLETE` | 人工確認發現資料問題 |
| `INCOMPLETE` | `WAITING_SUPPLIER` | 判定缺失資料需供應商補齊 |
| `INCOMPLETE` | `WAITING_BRAND` | 判定缺失資料需品牌方補齊 |
| `INCOMPLETE` | `WAITING_INTERNAL` | 判定缺失資料需內部處理 |

### 3.3 回補流程

| 起始狀態 | 目標狀態 | 轉換條件 |
|----------|----------|----------|
| `WAITING_SUPPLIER` | `PENDING_AI_CLEAN` | 供應商已補齊資料 |
| `WAITING_BRAND` | `PENDING_AI_CLEAN` | 品牌方已補齊資料 |
| `WAITING_INTERNAL` | `PENDING_AI_CLEAN` | 內部已補齊資料 |

### 3.4 轉入失敗處理

| 起始狀態 | 目標狀態 | 轉換條件 |
|----------|----------|----------|
| `T005_TRANSFERRING` | `READY_FOR_T005` | 轉入失敗，需重試 |
| `T005_TRANSFERRING` | `INCOMPLETE` | 轉入失敗，發現資料問題 |

## 四、狀態邏輯意義詳述

### 4.1 INCOMPLETE（資料不完整）

| 項目 | 說明 |
|------|------|
| 進入條件 | P0 或 P1 欄位有缺失 |
| 允許操作 | 判定責任方、分派回補任務 |
| 禁止操作 | 進行清洗、轉入 T005 |
| 退出條件 | 判定責任方後轉入 WAITING_* 狀態 |

### 4.2 WAITING_SUPPLIER（等待供應商）

| 項目 | 說明 |
|------|------|
| 進入條件 | 缺失資料責任方為供應商 |
| 邏輯意義 | 需向供應商請求補齊資料 |
| 退出條件 | 供應商補齊資料後重新進入清洗流程 |
| 逾期處理 | 依回補政策處理 |

### 4.3 WAITING_BRAND（等待品牌方）

| 項目 | 說明 |
|------|------|
| 進入條件 | 缺失資料責任方為品牌方 |
| 邏輯意義 | 需向品牌方請求補齊資料 |
| 退出條件 | 品牌方補齊資料後重新進入清洗流程 |
| 逾期處理 | 依回補政策處理 |

### 4.4 WAITING_INTERNAL（等待內部處理）

| 項目 | 說明 |
|------|------|
| 進入條件 | 缺失資料需內部人員處理 |
| 邏輯意義 | 內部可解決的資料問題 |
| 退出條件 | 內部處理完成後重新進入清洗流程 |

### 4.5 PENDING_AI_CLEAN（待 AI 清洗）

| 項目 | 說明 |
|------|------|
| 進入條件 | 新資料進入、回補資料完成 |
| 邏輯意義 | 資料已就緒，等待清洗 |
| 退出條件 | 清洗程序啟動 |

### 4.6 AI_CLEANING（AI 清洗中）

| 項目 | 說明 |
|------|------|
| 進入條件 | 清洗程序啟動 |
| 邏輯意義 | 清洗程序進行中 |
| 退出條件 | 清洗完成（成功或發現問題） |

### 4.7 PENDING_HUMAN_CONFIRM（待人工確認）

| 項目 | 說明 |
|------|------|
| 進入條件 | AI 清洗完成，信心度不足 |
| 邏輯意義 | 需人工審核清洗結果 |
| 退出條件 | 人工確認完成 |

### 4.8 READY_FOR_T005（可轉入 T005）

| 項目 | 說明 |
|------|------|
| 進入條件 | 資料完整，清洗完成（含人工確認） |
| 邏輯意義 | 資料品質達標，可轉入 T005 |
| 允許操作 | 啟動轉入程序 |
| 退出條件 | 轉入程序啟動 |

### 4.9 T005_TRANSFERRING（轉入中）

| 項目 | 說明 |
|------|------|
| 進入條件 | 轉入程序啟動 |
| 邏輯意義 | 資料正在同步至 T005 |
| 禁止操作 | 任何資料修改 |
| 退出條件 | 轉入完成或失敗 |

### 4.10 LOCKED_AFTER_T005（已轉入鎖定）

| 項目 | 說明 |
|------|------|
| 進入條件 | 轉入 T005 完成 |
| 邏輯意義 | T002 記錄成為歷史紀錄 |
| 允許操作 | 唯讀查詢 |
| 禁止操作 | 任何資料修改 |
| 永久狀態 | 此狀態不可逆 |

## 五、狀態與欄位關聯

### 5.1 狀態判定依據

| 判定項目 | 依據欄位 |
|----------|----------|
| 是否完整 | P0 + P1 欄位完整性 |
| 清洗狀態 | AI清洗狀態 |
| 信心度 | 信心度 |
| 人工確認 | 人工確認人、確認日期 |
| 轉入狀態 | T005轉入狀態、T005_UID |

### 5.2 狀態與 AI清洗狀態 對應

| 商品狀態 | AI清洗狀態 欄位值 |
|----------|------------------|
| `PENDING_AI_CLEAN` | 待處理 |
| `AI_CLEANING` | 處理中 |
| `PENDING_HUMAN_CONFIRM` | 需人工確認 |
| `READY_FOR_T005` | 清洗完成 |
| `LOCKED_AFTER_T005` | 清洗完成 |
