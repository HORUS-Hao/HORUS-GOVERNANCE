## 一、Purpose

本文件定義 T002 實作沙盒邊界，用於：

- 明確唯一允許的實作位置類型
- 宣告永久禁止的路徑
- 規範只能 Read-only 的資料
- 作為越界判定的依據

**任何越界行為 = 治理違規。**

---

## 二、沙盒定義

### 2.1 術語定義

| 術語 | 定義 |
|------|------|
| **Sandbox** | 隔離的實作環境，與正式資料完全分離 |
| **Shadow Sheet** | T002 主表的唯讀副本，僅供分析用 |
| **Mock Dataset** | 人造測試資料，無真實商品資訊 |
| **Derived Copy** | 從主表衍生的分析用副本（唯讀） |

### 2.2 沙盒原則

| 原則 | 說明 |
|------|------|
| 隔離性 | 沙盒與正式環境完全隔離 |
| 單向性 | 只能從正式環境讀取，不可寫回 |
| 可丟棄性 | 沙盒內容可隨時刪除，無影響 |
| 無副作用 | 沙盒操作不影響任何正式資料 |

## 三、唯一允許的實作位置類型

### 3.1 允許的位置類型

| 位置類型 | 說明 | 限制 |
|----------|------|------|
| **Sandbox Repository** | 獨立的沙盒 repo | 與正式 repo 分離 |
| **Sandbox Directory** | 正式 repo 內的沙盒目錄 | 明確標記隔離 |

| 資料 | 讀取方式 | 禁止行為 |
|------|----------|----------|

### 5.2 Read-only 強制措施

| 措施 | 說明 |

### 5.3 Read-only 違規判定

| 行為 | 判定 |
|------|------|
| 嘗試寫入 | 違規 |
| 繞過唯讀限制 | 嚴重違規 |
| 快取後修改再寫回 | 嚴重違規 |
| 任何副作用 | 違規 |

## 六、越界判定規則

### 6.1 越界定義

| 越界類型 | 定義 |
|----------|------|
| 位置越界 | 程式碼出現在禁止路徑 |
| 資料越界 | 對 Read-only 資料進行寫入 |
| 功能越界 | 實作超出批准的功能範圍 |
| 自動化越界 | 設定未授權的自動化 |

### 6.2 越界判定流程

```
發現可疑行為
     ↓
比對本文件規則
     ↓
位置是否在禁止路徑？ → 是 → 🔴 越界
     ↓ 否
資料操作是否為寫入？ → 是 → 🔴 越界
     ↓ 否
功能是否超出批准？ → 是 → 🔴 越界
     ↓ 否
     → ✅ 合規
```

### 6.3 越界後果

| 越界類型 | 後果 |
|----------|------|
| 位置越界 | 立即回滾，程式碼刪除 |
| 資料越界 | 立即停用，資料復原，調查 |
| 功能越界 | 刪除超出部分 |
| 自動化越界 | 立即移除觸發器 |

## 八、沙盒與正式環境隔離
