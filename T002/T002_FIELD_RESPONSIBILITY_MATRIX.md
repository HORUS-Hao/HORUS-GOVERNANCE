## 一、Purpose

本文件為 T002 欄位級責任矩陣，用於：

- 明確每個欄位的資料來源責任
- 定義欄位可否人工修改
- 標示進入 T005 後的鎖定狀態
- 識別影響 Canonical Key 的高風險欄位

**本文件為所有欄位衝突的最終裁判依據。**

## 三、來源責任定義

### 3.1 Supplier（供應商）

| 責任範圍 | 說明 |
|----------|------|
| 原始商品資料 | 商品名稱、規格、價格等原始資訊 |
| 資料準確性 | 確保提供資料正確無誤 |
| 缺漏回補 | 依通知補齊缺失資料 |

### 3.2 Brand（品牌方）

| 責任範圍 | 說明 |
|----------|------|
| 品牌資訊 | 官方品牌名稱、型號 |
| 授權確認 | 品牌授權相關資訊 |
| 品牌規範 | 品牌命名規則 |

### 3.3 Internal（內部）

| 責任範圍 | 說明 |
|----------|------|
| 供應商庫維護 | S001 供應商資料 |
| 清洗規則維護 | AI 清洗規則 |
| 人工確認 | 低信心度資料審核 |

### 3.4 System（系統）

| 責任範圍 | 說明 |
|----------|------|
| ID 產生 | T002_ID、T005_UID |
| 狀態管理 | 商品狀態轉換 |
| 時間戳記 | 建立/更新時間 |

## 四、人工補齊規則

### 4.1 可人工補齊的條件

| 條件 | 說明 |
|------|------|
| 欄位標記「可人工補」 | 本矩陣標記 ✅ 是 |
| 狀態允許修改 | 非 LOCKED_AFTER_T005 |
| 有明確來源 | 補齊資料有據可查 |

### 4.2 人工補齊流程

| 步驟 | 說明 |
|------|------|
| 1 | 確認欄位可人工補齊 |
| 2 | 記錄補齊來源 |
| 3 | 記錄補齊人員 |
| 4 | 狀態回到 PENDING_AI_CLEAN |

### 4.3 禁止人工補齊

| 欄位類型 | 原因 |
|----------|------|
| System 欄位 | 系統自動產生 |
| AI-Generated（未確認） | 需走確認流程 |
| 已鎖定欄位 | T005 後不可改 |

## 五、Canonical Key 影響評估

### 5.1 高風險欄位（影響 Canonical Key）

| 欄位 | 影響說明 | 錯誤後果 |
|------|----------|----------|
| T005_UID | 主鍵關聯 | 資料孤立 |
| 原廠商品名稱 | 商品識別 | 重複建檔 |
| 原廠品牌 | 品牌歸屬 | 分類錯誤 |
| 原廠型號 | 型號識別 | 混淆 |
| 供應商ID | 供應商關聯 | 責任不明 |
| 標準化名稱 | T005 商品名稱 | 主表錯誤 |
| 標準化品牌 | T005 品牌 | 主表錯誤 |
| 標準化型號 | T005 型號 | 主表錯誤 |

### 5.2 高風險欄位修改規則

| 規則 | 說明 |
|------|------|
| 必須人工確認 | 不可自動修改 |
| 必須記錄變更 | Change Log 必填 |
| 必須二次核對 | 另一人確認 |
| T005 後禁止修改 | 進入 T005 後鎖死 |

## 六、T005 後鎖定規則

### 6.1 鎖定行為

| 行為 | 說明 |
|------|------|
| 禁止修改 | 標記「T005後鎖定」的欄位不可改 |
| 禁止刪除 | 整筆記錄不可刪除 |
| 唯讀存取 | 僅供查詢追溯 |

### 6.2 例外情況

| 例外 | 處理方式 |
|------|----------|
| 發現重大錯誤 | 需 Architect ADR 裁定 |
| T005 退回 | 需完整流程回溯 |
| 法規要求 | 依法規處理 |
