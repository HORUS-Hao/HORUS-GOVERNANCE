# T002 / T005 資料邊界最終說明

**文件類型**: Governance Boundary Definition
**狀態**: Active
**適用範圍**: T002 / T005 模組邊界
**生效日期**: 2026-01-13
**上位文件**: ADR-T002-COLLABORATION-PHASE1.md

---

## 一、Purpose

本文件為 T002 與 T005 資料邊界的最終收斂說明，用於：

- 明確 T002 與 T005 的定位差異
- 宣告 Canonical Schema 歸屬
- 定義資料進入 T005 後的治理規則

本文件為**最終收斂文件**，不再開放討論。

---

## 二、核心宣告

### 2.1 Canonical 歸屬

| 宣告 | 說明 |
|------|------|
| **T002 ≠ Canonical** | T002 不是事實主表 |
| **T005 = Canonical** | T005 為唯一事實主表（Canonical Schema） |
| **T002 = Derived** | T002 為 T005 的衍生層 / 清洗層 |

### 2.2 模組定位

| 模組 | 定位 | 說明 |
|------|------|------|
| T005 | **FACT 層** | 商品主檔，唯一權威來源 |
| T002 | **準備層** | 原料清洗，資料進入前的準備區 |

### 2.3 依賴方向

| 關係 | 說明 |
|------|------|
| T005 不依賴 T002 | T005 不持有 T002_ID，不參照 T002 資料 |
| T002 依賴 T005 | T002 持有 T005_UID，表頭 IMPORTRANGE 對齊 T005 |

---

## 三、T002 存在定義

### 3.1 T002 存在時機

| 時機 | 說明 |
|------|------|
| 資料接收 | 從供應商 / 品牌方接收原始資料 |
| 資料清洗 | 標準化處理期間 |
| 人工確認 | 需人工審核期間 |
| 回補等待 | 等待缺漏資料補齊期間 |

### 3.2 T002 終止時機

| 時機 | 說明 |
|------|------|
| 轉入 T005 完成 | 資料成功進入 T005 |
| 商品放棄 | 判定不再處理該商品 |

### 3.3 T002 僅在「資料準備期」存在

| 宣告 | 說明 |
|------|------|
| T002 不是永久儲存 | T002 為過渡區，非長期資料庫 |
| T002 目的是進入 T005 | 所有 T002 記錄的目標是轉入 T005 |
| T002 無法取代 T005 | T002 不提供商品查詢、不對外開放 |

---

## 四、進入 T005 後的規則

### 4.1 T002 記錄狀態

| 規則 | 說明 |
|------|------|
| 狀態變更 | 轉入完成後，狀態變為 `LOCKED_AFTER_T005` |
| 唯讀 | T002 記錄成為唯讀，不可修改 |
| 歷史紀錄 | T002 保留作為資料來源追溯 |

### 4.2 唯讀治理聲明

| 聲明 | 說明 |
|------|------|
| 禁止修改 | 已轉入 T005 的 T002 記錄禁止任何修改 |
| 禁止刪除 | 禁止刪除已轉入的 T002 記錄 |
| 禁止重新轉入 | 同一 T002 記錄不可重複轉入 |

### 4.3 T005 後的資料維護

| 項目 | 責任歸屬 |
|------|----------|
| 資料修正 | T005 維護者 |
| 欄位補齊 | T005 維護者 |
| 品質問題 | T005 維護者 |

**宣告**：一旦進入 T005，T002 不再負責該商品資料。

## 六、表頭同步規則

### 6.1 同步方向

| 宣告 | 說明 |
|------|------|
| 單向同步 | T005 → T002（僅此方向） |
| IMPORTRANGE | T002 表頭透過 IMPORTRANGE 對齊 T005 |

### 6.2 表頭維護

## 七、治理邊界總結

### 7.1 T002 可以做

| 項目 | 說明 |
|------|------|
| 接收原始資料 | 從供應商 / 品牌方 |
| 清洗資料 | 標準化處理 |
| 人工確認 | 審核清洗結果 |
| 請求回補 | 向責任方請求缺漏資料 |
| 轉入 T005 | 資料完整後進行轉入 |

### 7.2 T002 不可以做

| 項目 | 說明 |
|------|------|
| 作為查詢來源 | T002 非對外資料來源 |
| 取代 T005 | T002 不是 Canonical |
| 修改 T005 | T002 無權修改 T005 |
| 重複轉入 | 同一記錄只能轉入一次 |
| 修改已鎖定記錄 | LOCKED_AFTER_T005 狀態不可修改 |

### 7.3 T005 可以做

| 項目 | 說明 |
|------|------|
| 作為唯一事實來源 | Canonical Schema |
| 對外提供資料 | 供其他系統查詢 |
| 維護商品資料 | 轉入後的資料維護 |
| 定義表頭結構 | Schema 權威 |

### 7.4 T005 不需要做

| 項目 | 說明 |
|------|------|
| 處理原始資料 | 由 T002 處理 |
| 清洗資料 | 由 T002 處理 |
| 向供應商請求資料 | 由 T002 處理 |
