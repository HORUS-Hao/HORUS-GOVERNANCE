# T002 商品資料完整性標準

**文件類型**: Governance Standard
**狀態**: Active
**適用範圍**: T002 原料清洗系統
**生效日期**: 2026-01-13
**上位文件**: ADR-T002-COLLABORATION-PHASE1.md

---

## 一、Purpose

本文件定義 T002 商品資料的完整性標準，用於：

- 判斷商品資料是否可建檔
- 判斷商品資料是否可轉入 T005
- 明確欄位分級與責任歸屬

本文件**不涉及任何實作方式**。

---

## 二、欄位分級定義

### 2.1 分級原則

| 等級 | 定義 | 建檔影響 | 轉入 T005 影響 |
|------|------|----------|----------------|
| **P0** | 無此欄位 = 不可建檔 | 阻斷建檔 | 阻斷轉入 |
| **P1** | 可建檔，但必須補齊 | 允許建檔 | 阻斷轉入 |
| **P2** | 延後補齊，不阻斷 | 允許建檔 | 允許轉入 |

### 2.2 分級裁定

#### P0 欄位（無此欄位 = 不可建檔）

| 欄位 | 來源類型 | 說明 |
|------|----------|------|
| T002_ID | System-Owned | 唯一識別碼，缺失則記錄不存在 |
| 供應商ID | System-Owned | 無供應商來源則資料無法追溯 |
| 原廠商品名稱 | Sync-Derived | 無商品名稱則無法識別商品 |

#### P1 欄位（可建檔，必須補齊後才可轉入 T005）

| 欄位 | 來源類型 | 說明 |
|------|----------|------|
| 標準化名稱 | AI-Generated | 轉入 T005 前必須有標準化名稱 |
| 標準化品牌 | AI-Generated | 轉入 T005 前必須有標準化品牌 |
| 標準化型號 | AI-Generated | 轉入 T005 前必須有標準化型號 |
| 原廠品牌 | Sync-Derived | 品牌資訊為標準化基礎 |
| 原廠型號 | Sync-Derived | 型號資訊為標準化基礎 |
| AI清洗狀態 | System-Owned | 必須為「清洗完成」或「需人工確認」已處理 |

#### P2 欄位（延後補齊，不阻斷建檔與轉入）

| 欄位 | 來源類型 | 說明 |
|------|----------|------|
| 原始價格 | Sync-Derived | 價格可後補 |
| 原始幣別 | Sync-Derived | 幣別可後補 |
| 備註 | Human-Input | 補充資訊，非必要 |
| 信心度 | AI-Generated | 輔助參考，非必要 |
| 確認日期 | Human-Input | 確認時自動填入 |
| 人工確認人 | Human-Input | 確認時自動填入 |
| 接收日期 | System-Owned | 資訊性欄位 |
| 供應商名稱 | Sync-Derived | 可由供應商ID反查 |

## 三、欄位來源分類

### 3.1 Canonical Reference（來自 T005）

| 欄位 | 說明 |
|------|------|
| T005_UID | 轉入 T005 後由系統填入 |
| T005轉入狀態 | 轉入流程狀態 |

**治理聲明**：此類欄位為 T005 Canonical Schema 之衍生，T002 不可自行修改。

### 3.2 T002 本地衍生欄位

| 欄位 | 來源類型 | 說明 |
|------|----------|------|
| T002_ID | System-Owned | T002 自有識別碼 |
| AI清洗狀態 | System-Owned | 清洗流程狀態 |
| 信心度 | AI-Generated | 清洗信心分數 |
| 標準化名稱 | AI-Generated | 清洗產出 |
| 標準化品牌 | AI-Generated | 清洗產出 |
| 標準化型號 | AI-Generated | 清洗產出 |
| 人工確認人 | Human-Input | 確認操作者 |
| 確認日期 | Human-Input | 確認時間 |
| 備註 | Human-Input | 補充資訊 |

### 3.3 外部同步欄位（Sync-Derived）

| 欄位 | 來源系統 | 說明 |
|------|----------|------|
| 供應商ID | S001 供應商庫 | 供應商識別 |
| 供應商名稱 | S001 供應商庫 | 供應商顯示名 |
| 原廠品牌 | 供應商提供 | 原始品牌名 |
| 原廠商品名稱 | 供應商提供 | 原始商品名 |
| 原廠型號 | 供應商提供 | 原始型號 |
| 原始價格 | 供應商提供 | 原始報價 |
| 原始幣別 | 供應商提供 | 原始幣別 |
| 接收日期 | 系統記錄 | 資料接收時間 |

## 四、完整性檢查規則

### 4.1 建檔前檢查

| 規則 | 條件 | 結果 |
|------|------|------|
| R-001 | P0 欄位任一為空 | 拒絕建檔 |
| R-002 | P0 欄位皆有值 | 允許建檔 |

### 4.2 轉入 T005 前檢查

| 規則 | 條件 | 結果 |
|------|------|------|
| R-101 | P0 欄位任一為空 | 拒絕轉入 |
| R-102 | P1 欄位任一為空 | 拒絕轉入 |
| R-103 | AI清洗狀態 ≠ 清洗完成 且 無人工確認 | 拒絕轉入 |
| R-104 | P0 + P1 皆完整 | 允許轉入 |

### 4.3 P2 欄位處理

| 規則 | 說明 |
|------|------|
| R-201 | P2 欄位缺失不阻斷任何流程 |
| R-202 | P2 欄位缺失應記錄於狀態欄位 |
| R-203 | P2 欄位可於轉入 T005 後補齊 |

## 五、責任歸屬

### 5.1 欄位責任矩陣

| 欄位類型 | 填寫責任 | 品質責任 |
|----------|----------|----------|
| System-Owned | 系統 | 系統維護者 |
| AI-Generated | 清洗引擎 | 清洗規則維護者 |
| Human-Input | 操作人員 | 操作人員 |
| Sync-Derived（供應商） | 供應商 | 供應商 |
| Sync-Derived（內部） | 來源系統 | 來源系統維護者 |

### 5.2 缺失責任判定

| 欄位來源 | 缺失時責任方 |
|----------|--------------|
| 供應商提供 | 供應商 |
| S001 供應商庫 | S001 維護者 |
| 清洗引擎 | 清洗規則維護者 |
| 人工操作 | 操作人員 |
| 系統自動 | 系統維護者 |
