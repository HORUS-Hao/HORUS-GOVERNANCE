## 一、Purpose

---

## 二、問題一：第一個實作只能是什麼

### 2.1 唯一允許的實作類型

| 聲明 | 說明 |
|------|------|
| **唯一類型** | **Read-only Data Validator** |
| 別名 | 資料驗證器 / 完整性檢查器 |
| 性質 | 純讀取、純分析、無副作用 |

### 2.2 Validator 定義

| 特性 | 說明 |
|------|------|
| 輸入 | T002 Shadow Sheet（唯讀副本） |
| 處理 | 欄位完整性檢查 |
| 輸出 | 驗證報告（文字 / JSON / Log） |
| 副作用 | **無**（零副作用） |

### 2.3 Validator 功能範圍

| 允許功能 | 說明 |
|----------|------|
| P0 欄位完整性檢查 | 檢查 P0 欄位是否有值 |
| P1 欄位完整性檢查 | 檢查 P1 欄位是否有值 |
| 格式驗證 | 檢查資料格式是否正確 |
| 狀態一致性檢查 | 檢查狀態與欄位是否一致 |
| 缺漏統計 | 統計缺漏數量與比例 |
| 報告輸出 | 產生驗證報告 |

### 2.4 Validator 輸出格式

```
T002 Data Validation Report
===========================
Generated: YYYY-MM-DD HH:MM:SS
Source: T002_SHADOW_READONLY

Summary:
- Total Records: N
- P0 Complete: N (N%)
- P1 Complete: N (N%)
- Status Consistent: N (N%)

P0 Gap Details:
| Row | T002_ID | Missing Fields |
|-----|---------|----------------|

P1 Gap Details:
| Row | T002_ID | Missing Fields |
|-----|---------|----------------|

Validation Complete. No data modified.
```

### 2.5 其他可考慮的第一實作類型（需另立 ADR）

| 類型 | 說明 | 狀態 |
|------|------|------|
| Analyzer | 資料分析器 | 需 ADR 授權 |
| Scanner | 資料掃描器 | 需 ADR 授權 |
| Reporter | 報表產生器 | 需 ADR 授權 |

## 三、問題二：明確禁止的行為

### 3.1 絕對禁止（🔴 紅線）

| 禁止行為 | 說明 | 原因 |
|----------|------|------|
| **寫入 Canonical** | 任何形式寫入 T005 | Canonical 邊界永久禁止 |
| **自動同步** | 任何自動資料同步 | 需另立 ADR |
| **自動補值** | 任何自動填入欄位 | 需另立 ADR |
| **修改 T002 主表** | 任何形式寫入主表 | 主資料保護 |
| **狀態變更** | 任何狀態轉換 | 需另立 ADR |
| **通知發送** | 任何通知發送 | 需另立 ADR |

### 3.2 寫入 Canonical 禁止詳述

| 禁止行為 | 說明 |
|----------|------|
| 直接寫入 T005 | 任何 API / Script 寫入 |
| 間接寫入 T005 | 透過中間層寫入 |
| 觸發寫入 T005 | 觸發其他程式寫入 |
| 建議寫入 T005 | 產生可直接執行的寫入指令 |
| 準備寫入 T005 | 準備待寫入的資料格式 |

**宣告：任何形式、任何理由、任何情況下，T002 實作皆不得寫入 T005。**

### 3.3 自動同步禁止詳述

| 禁止行為 | 說明 |
|----------|------|
| 定時同步 | 任何排程同步 |
| 觸發同步 | 事件觸發的同步 |
| 變更監聽同步 | 監聽變更後同步 |
| 批次同步 | 批次資料同步 |
| 增量同步 | 增量資料同步 |

**宣告：Validator 不可包含任何同步邏輯。**

### 3.4 自動補值禁止詳述

| 禁止行為 | 說明 |
|----------|------|
| 自動填入缺失欄位 | 任何自動補值 |
| AI 自動產生值 | AI 產生的自動填入 |
| 預設值填入 | 自動填入預設值 |
| 推測值填入 | 自動填入推測值 |
| 複製值填入 | 自動從其他欄位複製 |

**宣告：Validator 只讀取、只檢查、只報告，不填入任何值。**

### 3.5 其他禁止行為

| 禁止行為 | 原因 |
|----------|------|
| 建立 Trigger | 需另立 ADR |
| 建立 Webhook | 需另立 ADR |
| 呼叫外部 API | 需另立 ADR |
| 發送 Email | 需另立 ADR |
| 修改任何 Sheet | 沙盒限制 |
| 建立 Add-on | 需另立 ADR |

## 四、問題三：這個實作的唯一目的

### 4.1 唯一目的聲明

| 聲明 | 說明 |
|------|------|
| **唯一目的** | **驗證 T002 資料完整性並產生報告** |
| 核心價值 | 讓人看見問題，不是自動解決問題 |
| 行動者 | 人（看報告後決定行動） |
| 非目的 | 自動修復、自動同步、自動處理 |

### 4.2 目的拆解

| 目的要素 | 說明 |
|----------|------|
| 驗證 | 檢查資料是否符合標準 |
| T002 資料 | 僅限 T002（不含 T005） |
| 完整性 | 依 P0/P1/P2 分級 |
| 產生報告 | 輸出可閱讀的報告 |

### 4.3 目的邊界

| 在目的內 | 不在目的內 |
|----------|------------|
| 檢查欄位有無值 | 填入欄位值 |
| 檢查格式是否正確 | 修正格式 |
| 檢查狀態是否一致 | 變更狀態 |
| 統計缺漏數量 | 自動通知責任方 |
| 輸出報告 | 自動處理缺漏 |

### 4.4 目的達成判定

| 判定項目 | 達成標準 |
|----------|----------|
| 可執行 | 程式可正常執行 |
| 正確驗證 | 驗證結果與實際一致 |
| 完整報告 | 報告包含所有檢查項目 |
| 無副作用 | 執行後無任何資料變更 |

## 五、Validator 技術規格

### 5.1 輸入規格

| 項目 | 規格 |
|------|------|
| 資料來源 | T002 Shadow Sheet（唯讀） |
| 讀取方式 | IMPORTRANGE / SpreadsheetApp.openById |
| 權限要求 | Viewer 權限即可 |
| 資料範圍 | 全表或指定範圍 |

### 5.2 處理規格

| 項目 | 規格 |
|------|------|
| 處理方式 | 逐列檢查 |
| 檢查項目 | P0/P1/P2 欄位完整性 |
| 格式驗證 | 依欄位類型 |
| 狀態一致性 | 依狀態模型 |

### 5.3 輸出規格

| 項目 | 規格 |
|------|------|
| 輸出格式 | Text / JSON / Console Log |
| 輸出位置 | Console / Log Sheet（沙盒內） |
| 輸出內容 | 驗證摘要 + 詳細缺漏清單 |
| 禁止輸出 | 任何可執行的修改指令 |

### 5.4 執行規格

| 項目 | 規格 |
|------|------|
| 觸發方式 | 僅限人工執行 |
| 執行頻率 | 無限制（人工決定） |
| 執行時間 | 依資料量，建議 < 5 分鐘 |
| 失敗處理 | 輸出錯誤訊息，無重試 |
