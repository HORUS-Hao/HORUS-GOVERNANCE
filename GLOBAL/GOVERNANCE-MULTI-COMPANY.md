## 一、Purpose（目的與適用範圍）

本文件定義 HORUS-PDM 系統中「多公司」治理模型之概念與邊界。

**適用範圍**：
- 所有涉及公司識別、資料歸屬、跨公司操作之模組
- S005、V005 及其他依賴公司屬性之服務

**目的**：
- 確立公司作為資料隔離與權限邊界之基本單位
- 定義公司屬性與識別方式
- 規範跨公司操作之禁止事項

---

## 二、Company 定義

### 2.1 CompanyId（公司識別碼）

| 屬性 | 說明 |
|------|------|
| 識別方式 | `company_code`（唯一識別碼） |
| 格式 | 大寫英文字母組成（如 HORUS、DAPANDA） |
| 來源 | `Company_Profile.company_code` |
| 不可變性 | 一經建立不得變更 |

### 2.2 Company 屬性

| 屬性 | 說明 |
|------|------|
| `company_code` | 公司識別碼（唯一） |
| `company_name` | 公司顯示名稱 |
| `template_code` | 報價單模板代碼 |
| `stamp_file_id` | 預設印章 Drive File ID |
| `contact_*` | 聯絡資訊（人、電話、Email、地址） |
| `tax_id` | 統一編號 |
| `supervisor_emails` | 監管人 Email 清單 |

### 2.3 Company 邊界

| 邊界項目 | 說明 |
|----------|------|
| 資料歸屬 | 每筆報價單歸屬單一公司 |
| 印章歸屬 | 印章檔案歸屬單一公司 |
| 使用者關聯 | 使用者可被授權操作一至多家公司 |
| 權限隔離 | 不同公司之資料、印章、流程互不影響 |

## 三、Company 與資料歸屬原則

### 3.1 報價單歸屬

- 每筆報價單（`S005_QUOTES.ref_id`）歸屬單一公司
- 公司識別依據：`quote_company` 欄位
- 報價單一經建立，所屬公司不得變更

### 3.2 印章歸屬

- 印章檔案歸屬單一公司
- 印章識別依據：`Company_Profile.stamp_file_id`
- 報價單核准時，僅可使用該公司之印章

### 3.3 使用者資料歸屬

- 使用者帳號（`Admin_Users`）為全域資源
- 使用者與公司之關聯由 `USER_COMPANIES` 定義
- 使用者對特定公司之權限由 `USERS_ACCESS` 定義

---

## 四、跨公司隔離規則（禁止事項）

以下行為 **絕對禁止**：

| 禁止事項 | 說明 |
|----------|------|
| 跨公司存取報價單 | 使用者不得存取未授權公司之報價單 |
| 跨公司使用印章 | 不得將 A 公司印章用於 B 公司報價單 |
| 跨公司審批 | 不得以 A 公司身分核准 B 公司報價單 |
| 跨公司發送 | 不得以 A 公司名義發送 B 公司報價單 |
| 公司資料混用 | 不得將不同公司之聯絡資訊、模板混用 |

## 五、與 S005 / V005 的關係

### 5.1 S005（Submission Entry）

- S005 為報價單建立入口
- 建立報價單時需指定 `quote_company`
- S005 依據使用者之 `USER_COMPANIES` 授權決定可選公司

### 5.2 V005（Quotation Viewer）

- V005 為報價單檢視與操作介面
- V005 讀取報價單時，依據 `quote_company` 取得對應公司設定
- V005 顯示印章時，依據 Snapshot 中之 `stamp_file_id`
