# T002 Validation Reports

## Purpose

This directory contains read-only validation reports generated by the T002 Data Completeness Validator.

## Why This Validator Cannot Write Data

### Governance Constraints

This validator is governed by the following documents:

1. **ADR-T002-COLLABORATION-PHASE1.md** - Declares T002 as Derived Layer, not Canonical
2. **T002_ALLOWED_FIRST_IMPLEMENTATION.md** - First implementation must be Read-only Validator
3. **T002_EXECUTION_SANDBOX_BOUNDARY.md** - Any write operation = governance violation

### Explicit Prohibitions

| Prohibited Action | Reason |
|-------------------|--------|
| Write to T005 | Canonical boundary - permanently forbidden |
| Write to T002 | Main data protection |
| Auto-sync | Requires separate ADR |
| Auto-fill values | Requires separate ADR |
| Trigger any automation | Requires separate ADR |

### The Only Purpose

**Validate T002 data completeness and generate reports.**

- Input: T002 data (read-only)
- Process: Check P0/P1/P2 field completeness
- Output: Validation report (this directory)

### What Happens If Someone Tries to Write

1. Immediate rollback of any code changes
2. Investigation of the violation
3. Architect review and decision

## Report Format

Reports in this directory follow the naming convention:

```
T002_VALIDATION_REPORT_YYYY-MM-DD_HHMMSS.{md|csv|json}
```
