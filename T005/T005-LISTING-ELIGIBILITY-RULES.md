## 一、文件目的與適用範圍

### 1.1 目的

本文件定義「應上架商品」(Listing-Eligible Products) 的**商業規則與母數語義**，供以下模組在計算上架率時參照：

- **C005** Listing Checker
- **R020** Price Comparator
- **T030** Margin Simulation Center

### 1.2 適用範圍

本文件為**治理層文件**，定義商業規則與語義邊界。

### 1.3 Phase 聲明

> **Phase 1 (Current)**：僅定義規則，不修改任何程式碼，不回寫歷史資料。
>
> 本文件的所有內容皆為「應然」(should be) 描述，而非「實然」(is) 描述。
> 現行程式碼尚未實作本文件定義的 eligibility 邏輯。

## 二、資料來源與角色

### 2.1 資料層級定義

| 資料來源 | 層級 | 角色 | 說明 |
|----------|------|------|------|
| **T005** | FACTS | 商品主資料 | 商品狀態 (status) 為判定上架資格的**唯一依據** |
| **ERP** | FACTS | 庫存狀態 | **僅作為風險標註**，不影響上架資格判定 |
| **C005** | DERIVED | 平台上架事實 | 記錄各平台實際上架狀態，為比對結果 |

### 2.2 權威關係

```
T005 (SSOT) ──定義──> 應上架商品母數
     │
     └── C005 (DERIVED) ──比對──> 平台上架事實
                │
                └── 產出上架率 = 已上架數 / 母數
```

## 三、商品狀態 (status) 治理原則

### 3.1 現況說明

根據掃描結果（2026-01-22）：

- T005 Schema (`T005_SHEET_SCHEMA_CANONICAL_v2026-01.md`) 定義 `status` 欄位為 `string` 型別
- **目前未定義 enum 允許值清單**
- 已知存在的狀態值（來源：程式碼掃描）：
  - 正常銷售
  - 停止銷售
  - 庫存不足
  - 新品開發（預設值）
  - 停產（見於 T030）

### 3.2 現階段處理原則

由於 T005 `status` 欄位尚無正式 enum 定義：

> **暫不以商品狀態作為排除條件**
>
> 在 enum 正式定義並經 ADR 核准前，所有 T005 商品皆視為「應上架商品」。

### 3.3 未來補正項目

| 項目 | 說明 | 前置條件 |
|------|------|----------|
| T005 status enum 定義 | 在 Schema 中明確定義允許值 | Schema 變更 ADR |
| 狀態 → 上架資格對照表 | 定義哪些狀態屬於「應上架」 | enum 定義完成 |
| C005 eligibility filter | 實作母數過濾邏輯 | 對照表核准 |

## 四、ERP 庫存判斷（風險層，非母數層）

ERP 庫存**不作為是否應上架的判斷依據**。

原因包括但不限於：
- 尚未進貨但已開放上架 / 預購
- 採購在途（PO 已成立）
- 直出 / 代發商品
- 平台允許無庫存上架

### 4.1 庫存角色定義

- ERP 庫存僅用於「營運風險標註」
- 不影響：
  - 應上架商品母數
  - 上架率分母計算

### 4.2 建議用途（未來 Phase）

- 無庫存但已上架 → 風險提醒
- 無庫存且未上架 → 僅供參考，不判定為異常

> 是否將 ERP 庫存納入母數排除，需另立 ADR，不得隱性調整。

## 五、現階段限制與已知缺口

### 5.1 程式碼現況（截至 2026-01-22）

| 模組 | 檔案 | 現況 | 與本規則差異 |
|------|------|------|--------------|
| C005 | `ComparisonEngine.js:226` | `totalProducts = annotatedResults.length` | 未實作 eligibility filter |
| C005 | `buildBaseProducts()` | ERP + T005 聯集 | 未依商品狀態過濾 |
| T030 | `T030_Proposal.js:330` | 排除 `status === '停產'` | 已有部分實作，但未治理化 |

### 5.2 上架率母數定義

> **現行定義**：上架母數 = T005 + ERP 聯集之全部商品數
>
> 此為「最大母數版本」，包含所有商品，不論其狀態。

### 5.3 資訊揭露要求

在 eligibility 規則正式實作前，以下報表/郵件應揭露母數定義：

| 輸出管道 | 建議標註文字 |
|----------|--------------|
| C005 MAIL | 「母數 = T005 + ERP 全商品，尚未依商品狀態排除」 |
| C005 Web 報表 | 同上 |
| R020 相關報表 | 若引用上架率，需同步標註 |
